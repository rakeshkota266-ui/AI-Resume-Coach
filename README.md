# 🤖 Universal Agentic AI Resume & Career Coach

An AI-powered resume and career coaching platform that analyzes resumes, evaluates ATS readiness, identifies suitable career paths, matches resumes with job descriptions, detects skill gaps, improves resume content, and generates personalized career roadmaps.

## 🚀 Features

### 📄 Resume Analysis
- Upload a PDF resume
- Extract resume text automatically
- Analyze skills, education, projects, experience, email, and phone
- Generate an ATS score
- Provide resume improvement suggestions

### 🎯 AI Career Discovery
- Analyze the candidate's resume
- Identify suitable career paths
- Provide career match percentages
- Explain why each career is suitable
- Identify missing skills
- Recommend areas for improvement

### 💼 Job Matching
- Paste any job description
- Extract required skills
- Compare job requirements with resume skills
- Calculate a job match score
- Show matched skills
- Show missing skills
- Highlight high-priority skills
- Recommend skills to develop

### ✍️ AI Resume Coach
- Analyze the existing resume
- Suggest improvements
- Improve resume content using AI
- Provide professional recommendations

### 🛣️ AI Career Roadmap
- Identify skill gaps
- Generate a beginner-to-advanced learning path
- Recommend projects
- Suggest learning priorities
- Provide a job-readiness roadmap
